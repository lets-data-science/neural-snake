Neural Snake: fair speed benchmark (dev tool, not deployed)

Loads web/model/snake.onnx and the vendored runtime from web/vendor/. Two separate sessions, each with exactly one execution provider: ['webgpu'] (webgpu bundle) and ['wasm'] (wasm bundle, 1 thread). Per session: session-create time, 50 warm-up steps (excluded), then 500 timed closed-loop steps (model output fed back; food sampled like the game page; game over resets to the start state).

Order: webgpu first (default) · wasm first. Close other tabs and keep this tab in the foreground.
